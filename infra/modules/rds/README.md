# rds

PostgreSQL instance, its subnet group and parameter group, and the Secrets Manager
secret holding its credentials.

## Design notes

- **The master password never exists as an input.** It is generated by
  `random_password` and written straight to Secrets Manager. There is deliberately no
  password variable, nothing in tfvars, and no output that exposes it.
- **The secret document is written after the instance exists,** so it carries the real
  endpoint. A consumer needs this secret and nothing else to connect.
- **The secret name is passed in rather than derived here,** so the `security` module
  can scope its IAM policy to the same name without a dependency cycle.
- **`rds.force_ssl = 1`** in the parameter group, so unencrypted connections are
  refused at the server rather than trusted to the client.
- **Storage is encrypted and the instance is not publicly accessible.**

## Simplifications

- **Single-AZ.** `multi_az` defaults to false. The architecture diagram shows Multi-AZ;
  this environment trades the standby for cost. Failover would otherwise be automatic;
  as configured, an AZ loss means a restore from backup.
- **`db.t4g.micro`, no read replica.** Sized for tens of runs a day against megabyte
  inputs. There is no read traffic to offload.
- **No RDS Proxy.** Fargate tasks are long-lived and pool connections, so the total is
  bounded by `max_tasks x pool_size` at plan time. RDS Proxy solves Lambda-style
  connection storms, which this design does not have.
- **Enhanced monitoring is off** (`monitoring_interval_seconds = 0`), which avoids an
  extra IAM role and per-instance CloudWatch cost. Performance Insights is on, free at
  seven days.

## Inputs

| Name | Description | Type | Default | Required |
| ---- | ----------- | ---- | ------- | :------: |
| name\_prefix | Prefix applied to every resource name in this module. | `string` | n/a | yes |
| secret\_name | Secrets Manager secret name for the credentials. Passed in rather than derived, because the security module scopes its IAM policy to this same name. | `string` | n/a | yes |
| security\_group\_ids | Security groups attached to the instance. | `list(string)` | n/a | yes |
| subnet\_ids | Isolated subnets for the DB subnet group. | `list(string)` | n/a | yes |
| allocated\_storage | Initial storage in GiB. | `number` | `20` | no |
| backup\_retention\_days | Days of automated backups to retain. | `number` | `7` | no |
| backup\_window | Daily backup window in UTC. Set to the small hours in the deployment region. | `string` | `"17:00-18:00"` | no |
| db\_name | Name of the initial database created on the instance. | `string` | `"pipeline"` | no |
| deletion\_protection | Whether the instance refuses deletion. | `bool` | `true` | no |
| engine\_version | PostgreSQL major version. Minor upgrades are applied automatically in the maintenance window. | `string` | `"16"` | no |
| instance\_class | RDS instance class. | `string` | `"db.t4g.micro"` | no |
| log\_min\_duration\_statement\_ms | Statements slower than this are logged. Tuned to catch the transformation's write path without logging every query. | `number` | `1000` | no |
| maintenance\_window | Weekly maintenance window in UTC, placed after the backup window. | `string` | `"Sun:18:30-Sun:19:30"` | no |
| master\_username | Master username. Not a secret; the password it pairs with is generated and stored separately. | `string` | `"pipeline_admin"` | no |
| max\_allocated\_storage | Ceiling in GiB for storage autoscaling. Set equal to allocated\_storage to disable it. | `number` | `100` | no |
| monitoring\_interval\_seconds | Enhanced monitoring granularity. Zero disables it and avoids the extra IAM role and CloudWatch cost. | `number` | `0` | no |
| multi\_az | Whether to run a standby in a second AZ. False in this environment as a documented simplification; production would set it true. | `bool` | `false` | no |
| performance\_insights\_enabled | Whether to enable Performance Insights. Free at seven days' retention on supported classes. | `bool` | `true` | no |
| secret\_recovery\_window\_days | Days Secrets Manager retains a deleted secret before purging it. Zero allows immediate reuse of the name, which matters when tearing a dev environment down and back up. | `number` | `7` | no |
| skip\_final\_snapshot | Whether to skip the final snapshot on destroy. True only for disposable environments. | `bool` | `false` | no |

| Name | Description |
| ---- | ----------- |

| db\_name | Name of the initial database. |
| endpoint | Connection endpoint in host:port form. |

| instance\_identifier | Instance identifier, the form CloudWatch metric dimensions require. |
| port | Port the instance listens on. |
